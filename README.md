## 📌 Project Overview

This project is an HR Analytics Dashboard created using Microsoft Power BI.

The main objective of this project is to analyze employee data and help HR teams understand employee attrition, workforce structure, salary, job roles, and employee satisfaction.

## 🎯 Business Objectives

- Analyze total and active employees
- Understand employee attrition
- Identify departments with high attrition
- Analyze employee salary and job roles
- Understand employee satisfaction and performance
- Provide useful insights for employee retention
